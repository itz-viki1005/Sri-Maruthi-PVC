# 🏠 Sri Maruthi PVC Interiors

A modern and responsive interior design website built using React and Vite.

---

## 📖 About

Sri Maruthi PVC Interiors is a modern and responsive website developed for an interior design business. It showcases interior services, completed projects, pricing, gallery, and contact information. Customers can also connect directly through WhatsApp for consultations.
